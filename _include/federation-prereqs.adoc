.Bevor Sie beginnen
* Es ist ein IdP-Konto mit Administratorrechten erforderlich.  Koordinieren Sie die Durchführung der Schritte mit Ihrem IdP-Administrator.
* Wählen Sie die Domäne aus, die Sie für die Föderation verwenden möchten. Sie können Ihre E-Mail-Domäne oder eine andere Domäne verwenden, die Ihnen gehört. Wenn Sie eine andere Domäne als Ihre E-Mail-Domäne verwenden möchten, müssen Sie die Domäne zuerst in der Console verifizieren. Anweisungen dazu finden Sie unter link:task-federation-verify-domain.html["Überprüfen Sie Ihre Domäne in der NetApp Console"].
