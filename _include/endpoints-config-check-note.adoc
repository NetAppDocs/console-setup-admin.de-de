[IMPORTANT]
====
* Bei neuen Agentenbereitstellungen prüft NetApp die folgenden Endpunkte: link:reference-networking-saas-console.html["hier aufgeführt"^]. Diese Konfigurationsprüfung schlägt mit einem Fehler fehl, wenn Sie die vorherigen Endpunkte für Upgrades verwenden, link:reference-networking-saas-console-previous.html["hier aufgeführt"]. NetApp empfiehlt, Ihre Firewall-Regeln so bald wie möglich zu aktualisieren, um den Zugriff auf die aktuellen Endpunkte zu erlauben und den Zugriff auf die vorherigen Endpunkte zu blockieren. link:reference-networking-saas-console-previous.html#update-endpoint-list["Erfahren Sie, wie Sie Ihr Netzwerk aktualisieren"].
* Wenn Sie die Endpunkte in Ihrer Firewall aktualisieren, funktionieren Ihre vorhandenen Agenten weiterhin.
