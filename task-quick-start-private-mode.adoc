= Erste Schritte Arbeitsablauf für die NetApp Console im privaten Modus
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Sie können NetApp Console lokal oder in einer sicheren Cloud-Umgebung installieren. Der private Modus wird typischerweise in lokalen Umgebungen ohne Internetverbindung und in sicheren Cloud-Regionen verwendet, zu denen  https://aws.amazon.com/federal/secret-cloud/["AWS Secret Cloud"^],  https://aws.amazon.com/federal/top-secret-cloud/["AWS Top Secret Cloud"^] und  https://learn.microsoft.com/en-us/azure/compliance/offerings/offering-dod-il6["Azure IL6"^] gehören.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Eins"] link:task-prepare-private-mode.html["Vorbereiten der Bereitstellung"]
[role="quick-margin-list"]
. Bereiten Sie einen dedizierten Linux-Host vor, der die Anforderungen hinsichtlich CPU, RAM, Speicherplatz, Container-Orchestrierungstool und mehr erfüllt.
. Richten Sie das Netzwerk so ein, dass es den Zugriff auf die Zielnetzwerke ermöglicht.
. Für Cloud-Bereitstellungen richten Sie Berechtigungen bei Ihrem Cloud-Anbieter ein, damit Sie diese Berechtigungen nach der Installation der Software dem Console-Agenten zuordnen können.


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Zwei"] link:task-install-private-mode.html["Bereitstellen des Konsolenagenten"]
[role="quick-margin-list"]
. Installieren Sie den Console Agent auf Ihrem eigenen Linux-Host.
. Richten Sie die NetApp Console ein, indem Sie einen Webbrowser öffnen und die IP-Adresse des Linux-Hosts eingeben.
. Für Cloud-Bereitstellungen stellen Sie der NetApp Console die Berechtigungen bereit, die Sie zuvor eingerichtet haben.




== Unterstützte Funktionen und Dienste für NetApp Console im privaten Modus

Die folgende Tabelle listet die Speicherverwaltungsfunktionen, Datendienste und administrativen Funktionen auf, die in der NetApp Console bei der Installation im privaten Modus verfügbar sind. Die Funktionen unterscheiden sich, je nachdem, ob Sie die NetApp Console in der Cloud oder vor Ort installieren.

|===
| Produktbereich | NetApp service oder Funktion | Konsolenagent erforderlich 


.2+| *Verwaltung von Speichersystemen* Dieser Abschnitt der Tabelle listet die Unterstützung für die Verwaltung von Speichersystemen von der NetApp Console auf. Er gibt nicht die unterstützten Sicherungsziele für NetApp Backup and Recovery an. | Cloud Volumes ONTAP | Ja, aber da kein Internetzugang besteht, sind die folgenden Funktionen nicht verfügbar: automatisierte Software-Upgrades und AutoSupport.

* Erfordert Konnektivität von der Cloud (wo der Console-Agent installiert ist) zur lokalen Umgebung.
+

| Sie können die direkte Erkennung ohne einen Console-Agent verwenden, aber Sie benötigen einen Agenten, um Verwaltungsfunktionen zu nutzen. 


.3+| *Datendienste*  a| 
Backup and Recovery

* Im privaten Modus unterstützt NetApp Backup and Recovery nur die Sicherung und Wiederherstellung von ONTAP-Volume-Daten. https://docs.netapp.com/us-en/data-services-backup-recovery/prev-ontap-protect-journey.html#support-for-sites-with-no-internet-connectivity["Sehen Sie sich die Liste der unterstützten Backup-Ziele für ONTAP -Daten an"^] Die Sicherung und Wiederherstellung von Anwendungsdaten und virtuellen Maschinendaten wird nicht unterstützt.
* Wird in Google Cloud oder in https://aws.amazon.com/federal/secret-cloud/["AWS Secret Cloud"^], https://aws.amazon.com/federal/top-secret-cloud/["AWS Top Secret Cloud"^] oder https://learn.microsoft.com/en-us/azure/compliance/offerings/offering-dod-il6["Azure IL6"^] nicht unterstützt

| Ja 


 a| 
NetApp Klassifizierung

* Die einzigen unterstützten Datenquellen sind diejenigen, die Sie lokal ermitteln können. https://docs.netapp.com/us-en/data-services-data-classification/task-deploy-compliance-dark-site.html#supported-data-sources["Zeigen Sie die Quellen an, die Sie lokal entdecken können"^]
* Funktionen, die einen ausgehenden Internetzugang erfordern, werden nicht unterstützt. https://docs.netapp.com/us-en/data-services-data-classification/task-deploy-compliance-dark-site.html#limitations["Funktionsbeschränkungen anzeigen"^]

| Ja

| *NetApp Supportvertragsfunktionen* | Keine | --

Licenses and subscriptions-Verwaltung

+
