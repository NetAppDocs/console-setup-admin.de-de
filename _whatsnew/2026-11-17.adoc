[[console-agent-4-13-0]]
=== Console Agent 4.13.0

Die Version 4.13.0 unterstützt sowohl den Standardmodus als auch den eingeschränkten Modus.

Diese Version des Console Agenten enthält Sicherheitsverbesserungen und Fehlerbehebungen sowie die folgende neue Funktion. Beim Upgrade eines über vCenter bereitgestellten Console Agenten auf 4.13.0 mithilfe einer ISO-Datei ist nach Abschluss des Upgrades ein Neustart der VM erforderlich. Die VM startet möglicherweise automatisch neu.



==== Beim Einsatz eines Console Agenten wird die AWS Deployment Rolle automatisch erstellt.

Sie müssen die IAM-Rolle für den Einsatz eines Console Agenten in AWS nicht mehr erstellen, bevor Sie beginnen. Die NetApp Console kann die Rolle für Sie erstellen. link:https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-console.html["So setzen Sie einen Console Agenten in AWS über die Console ein"^]



[[netapp-console-administration]]
=== NetApp Console

Diese Version enthält Sicherheitsverbesserungen und Fehlerbehebungen sowie die folgende neue Funktion.



==== Zuweisen der Cloud Volumes ONTAP Mitwirkendenrolle

Ihnen kann jetzt die Rolle „Cloud Volumes ONTAP contributor“ zugewiesen werden, um Mitgliedern umfassenden Zugriff zum Managen von Cloud Volumes ONTAP Systemen zu geben, ohne ihnen das Löschen von Systemen, Volumes, Aggregaten oder Replikationsbeziehungen zu ermöglichen link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-cvo-roles.html["Weitere Informationen über rollenbasierte Zugriffssteuerung für Cloud Volumes ONTAP"^].
