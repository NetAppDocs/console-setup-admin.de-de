=== Console Agent 4.11.0

Die Version 4.11.0 unterstützt sowohl den Standardmodus als auch den eingeschränkten Modus.

Diese Version des Console-Agenten enthält Sicherheitsverbesserungen und Fehlerbehebungen.



[[netapp-console-administration]]
=== NetApp Console



==== Vereinfachter Agentenbereitstellungsprozess für Cloud Volumes ONTAP Abonnenten im AWS Marketplace

Wenn Sie ein neues Abonnement für eine link:https://us-east-1.console.aws.amazon.com/marketplace/search/listing/prodview-yi43o6oz7bf32?sr=0-2&ref_=ucaf&applicationId=AWS-Marketplace-Console["eigenständiges Cloud Volumes ONTAP Abonnement im AWS Marketplace"] haben, vereinfacht die NetApp Console jetzt die Agentenbereitstellung. AWS-Rollen, -Richtlinien und -Anmeldeinformationen lassen sich mit weniger Schritten konfigurieren, Standardwerte werden automatisch auf einer einzigen Seite verwendet, und der Einrichtungsprozess erfolgt schneller.
