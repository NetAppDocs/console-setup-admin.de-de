= Cloud Volumes ONTAP Zugriffsrollen in der NetApp Console
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Sie können Benutzern die folgenden Rollen zuweisen, um ihnen Zugriff auf Cloud Volumes ONTAP innerhalb der NetApp Console zu ermöglichen.

* *Cloud Volumes ONTAP Admin*: Bietet vollständigen Zugriff auf alle Cloud Volumes ONTAP Operationen.
* *Cloud Volumes ONTAP Operator*: Führt wichtige Speicheroperationen durch, wie das Erkennen und Verwalten von Cloud Volumes ONTAP Systemen, einschließlich des Hinzufügens von Volumes, Aggregaten, Snapshots und Replikationen, das Ändern bestimmter Konfigurationen sowie das Aktualisieren von Cloud Volumes ONTAP Versionen.
* *Cloud Volumes ONTAP viewer*: Bietet nur Lesezugriff auf Cloud Volumes ONTAP Informationen. Diese Rolle kann keine aktiven Operationen ausführen. Einige Registerkarten und Bildschirme mit Konfigurationsinformationen sind für Viewer möglicherweise nicht verfügbar.


link:reference-iam-predefined-roles.html["Informationen zu Zugriffsrollen"] .

Cloud Volumes ONTAP Rollen auf der Organisationsebene, Ordnerebene oder Projektebene zuweisen, die das System enthält. Plattformrollen ermöglichen es Benutzern, NetApp Console Ressourcen zu verwalten, während Cloud Volumes ONTAP Rollen es Benutzern ermöglichen, Cloud Volumes ONTAP Systeme zu verwalten. Hinweise zur Planung von Rollenzuweisungen finden sich unter link:task-cvo-rbac-setup.html#plan-cloud-volumes-ontap-role-assignments["Rollenbasierter Zugriff für Cloud Volumes ONTAP einrichten"].



[[role-migrations-for-existing-users]]
== Rollenmigrationen für bestehende Benutzer

Beim Upgrade eines Console-Agenten auf Version 4.9.0 oder höher weist die Console bestehenden Benutzern basierend auf ihren Plattformrollen zusätzliche Cloud Volumes ONTAP Rollen zu.


NOTE: Wenn ein vorhandener Console-Agent auf Console 4.9.0 oder höher aktualisiert wird, führt die Console einen einmaligen Initialisierungsprozess durch, der bestehenden Benutzern in der Organisation Cloud Volumes ONTAP Rollen zuweist. Dieser Vorgang kann bis zu 30 Minuten dauern. Zum Überprüfen und Anpassen der initialisierten Rollen siehe link:task-cvo-rbac-setup.html#review-roles-after-upgrading-the-console-agent["Rollen nach dem Upgrade des Console-Agenten überprüfen"].

Die folgenden Zuordnungen gelten nur für diesen einmaligen Migrationsprozess.

[cols="50,50"]
|===
| Vorhandene Plattformrolle | Cloud Volumes ONTAP Rolle während des Seedings zugewiesen 


| Super-Admin | Cloud Volumes ONTAP Administrator 


| Organisationsadministrator | Cloud Volumes ONTAP Administrator 


| Föderationsadministrator | Cloud Volumes ONTAP Administrator 


| Ordner- oder Projektadministrator | Cloud Volumes ONTAP Administrator 


| Super Viewer | Cloud Volumes ONTAP Viewer 


| Organisationsanzeige | Cloud Volumes ONTAP Viewer 


| Föderationsbetrachter | Cloud Volumes ONTAP Viewer 


| Ordner oder Projektbetrachter | Cloud Volumes ONTAP Viewer 


| Jede andere Plattformrolle | Cloud Volumes ONTAP Viewer 
|===
Die Konsole weist die Cloud Volumes ONTAP Rolle auf derselben Hierarchieebene wie die bestehende Plattformrolle zu. Diese Zuordnungen gelten nicht für neue Rollenzuweisungen. Eine Übersicht und Anpassungsmöglichkeiten für vordefinierte Rollen finden sich unter link:task-cvo-rbac-setup.html#review-roles-after-upgrading-the-console-agent["Rollen nach dem Upgrade des Console-Agenten überprüfen"].


NOTE: Ein bekanntes Problem verhindert derzeit, dass die Rollenkombination *Organization viewer* und *Cloud Volumes ONTAP viewer* auf Organisationsebene funktioniert. Als temporäre Lösung kann die Rolle *Organization admin* oder *Folder or project admin* verwendet werden.



[[how-role-changes-take-effect]]
== Wie sich Rollenänderungen auswirken

Es kann bis zu einer Stunde dauern, bis neue oder aktualisierte Rollenzuweisungen wirksam werden. Cloud Volumes ONTAP aktualisiert die Rollenzuweisungen stündlich.
